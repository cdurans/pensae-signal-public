# Browser test boundary

Production-like critical browser scenarios use fake backend capabilities without public internet,
GPU, model weights, or live llama.cpp servers.

## Phase 7 required coverage

Fake Chromium must cover target/reserve progress, five unique sequential
commits with five portfolio/detail links, non-counting exact/Updated/Possible rediscovery and invalid
candidates, honest no-filler shortfall, precise work-limit display, refresh/reconnect, and later
failure/Stop with prior commits intact. The fake backend proves deterministic UI/API behavior only.

Phase 7 G9 separately requires an operator-approved `make start` run through the real FastAPI-served
website with local models and SearXNG. Fake browser evidence must never be reported as live
model/search quality, GPU, process ownership, or five-opportunity release evidence.
